Створення маршрутів: назва, тип (🚶/🚗), колір\
Клік по карті → форма (дата, час, примітка) → точка додається до активного маршруту\
Лінія маршруту зі стрілками напрямку кольору маршруту\
Список маршрутів з галочками показу/приховування (фільтр)\
Розгортання маршруту → таблиця точок з видаленням\
💾 Зберегти JSON — качає routes.json з усіма даними\
📂 Завантажити JSON — імпортує його назад (на будь-якому іншому комп'ютері, де є цей самий HTML-файл)\
